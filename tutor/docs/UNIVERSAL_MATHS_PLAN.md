# Universal maths library — first implementation

The app now separates **central concepts** from **curriculum placement**. Open Universal maths in the top navigation. Chapters contain focused subtopics with stable IDs. Prepared introductions open the existing voice classroom. Missing lessons open Teaching system with the exact central context; use the existing connected generation button, review the draft, and approve it. An approved central plan becomes available from the library without recreating it for each curriculum.

The first manifest covers school maths chapters: number, fractions and ratios, powers, algebra, relations, geometry, statistics and probability, modelling, coding, finance, and mathematical thinking. It reuses the original sample lessons and the 39 Grade 9 skill introductions, and adds 10 focused lessons for equations on both sides, brackets, fractional equations, missing right-triangle legs, unlike denominators, fraction multiplication, unit rates, compound interest, scientific notation and roots.

Ontario MTH1W has explicit prototype mappings for all 46 curriculum entries. One entry can map to multiple concepts. Missing and prepared subskills are shown separately so an introductory lesson is not mistaken for complete coverage. The mapped central lesson list appears in chapter details. The original Ontario curriculum lessons and progress remain available.

Suggested grades in the central manifest are starting points, not rules for every country's curriculum. The universal library is not yet a complete Grades 1–12 course. It does not contain verified curriculum mappings for every country. New country curricula need sourced expectation records and reviewed mappings, then can reuse these central concept IDs.

AI generation currently requires clicking Generate draft and a configured private test backend. Drafts are structurally validated and require review; they never silently become approved teaching content. Full mathematical accuracy, age suitability and curriculum coverage require review. Open-ended and research activities are not automatically graded.

The central library is bundled with the app; generated plans and student progress are saved on this device. Export library and mappings provides a portable JSON snapshot for future Base44 migration. Cross-device shared storage, per-subskill curriculum mastery aggregation, prerequisite routing, translations, and additional depth/difficulty variants remain to implement. Existing per-topic curriculum completion is not proof that every mapped subskill is mastered.
