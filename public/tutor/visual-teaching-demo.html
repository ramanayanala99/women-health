Replay a drawing, change a value, and compare the result. These browser-only teaching tools run independently of the tutor, AI connection and database. The same tools support the matched Grade 7 and Grade 8 voice lessons.

Scientific notation uses a × 10ⁿ with a normalised coefficient. “Read this model” speaks mathematical symbols in English. Speech is optional and never requests your microphone.

Reuse these tools in another web app

Copy maths-notation.js, visual-teaching.js and visual-teaching.css into the other app. Load the notation script before the visual script, then call MathsVisualTeaching.mount(container, { kind: 'graph' }). Destroy the mounted instance when the container leaves the page.

These visual modules need no framework or Netlify backend. The complete tutor still needs its classroom integrations and same-origin AI and progress endpoints. A native mobile app needs a web view or a separate native implementation; browser speech availability varies.
